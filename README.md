# Doppel.fit Image Search Userscript

A browser userscript that adds seamless reverse image search integration with **Doppel.fit** directly from your web browser. Built via vibe coding.

## Features

- 🔍 **Overlay Search Button**: Appears in the top-right corner when hovering over image results on Google Images.
- ⚡ **Shortcut Trigger**: Fast search trigger using `Alt + Right Click` directly on any image.
- 🌐 **Automatic Updates**: Configured with `downloadURL` and `updateURL` via GitHub Raw for seamless script updates via Violentmonkey or Tampermonkey.

## Installation

1. Install a userscript manager extension for your browser:
   - [Violentmonkey](https://violentmonkey.github.io/) (Recommended)
   - [Tampermonkey](https://www.tampermonkey.net/)
2. Click the following link to install the script directly:
   - [Install Doppel.fit Image Search Script](https://raw.githubusercontent.com/Rootzpower/Doppel.fit-Image-Search/main/Doppel.fit_Image-Search.js)
3. Confirm the installation in your userscript manager prompt.

## Usage

* **Method 1 (Hover Button)**: Search on Google Images, hover your mouse over any image thumbnail or full preview, and click the **🔍 Doppel.fit** button.
* **Method 2 (Hotkey)**: Hold the `Alt` key and `Right-Click` on any image on Google Images to immediately upload and search.
